# Final Acceptance Checklist

Complete this once after deployment.

## Administrator

- [ ] Personal email signs in and shows **Administrator**.
- [ ] Dashboard totals match the imported Sheet.
- [ ] Reports, Team and Settings are visible.
- [ ] Add/edit/delete a temporary lead, then remove it.
- [ ] Create a temporary task, mark it done and delete it.
- [ ] Convert or add one real signed client and add its correct monthly scope.
- [ ] Add one payment record and confirm staff cannot see it.

## Google Sheet

- [ ] Test connection shows the intended spreadsheet and `leads new` tab.
- [ ] Detected header row is correct.
- [ ] Import preview counts look reasonable before applying.
- [ ] Review items are individually resolved.
- [ ] Several imported names, phones, statuses and notes match the Sheet.
- [ ] CRM IDs appear in the Sheet after import.
- [ ] First CRM-to-Sheet sync is performed only after verification.
- [ ] Sheet title, formatting and dropdowns remain intact.

## Team Member

- [ ] Staff login shows only My Dashboard, My Leads, My Pipeline, My Follow-ups, My Clients, Activities and Quick Replies.
- [ ] Staff cannot open Reports, Team or Settings by URL.
- [ ] Staff cannot see monthly fees or payment records.
- [ ] Staff sees an assigned task and the related lead/client context.
- [ ] Staff can update only assigned deliverable/shoot progress.
- [ ] Staff sees no delete controls.

## Devices

- [ ] Mac/Windows desktop layout is usable.
- [ ] iPhone/Android navigation opens and closes correctly.
- [ ] App can be installed to the home screen when desired.
- [ ] Offline mode shows read-only status and does not pretend a save succeeded.
